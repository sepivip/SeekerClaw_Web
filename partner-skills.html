How to Install This Skill

Option 1: Send Install Link Easiest

Click "Send to Agent" above to copy the install link, then paste it to your SeekerClaw agent in Telegram:

Option 2: Send as File

Click "Download .md" above, then send the downloaded .md file directly to your agent in Telegram. It will read and install it automatically.

After installation, your agent will automatically detect the new skill on the next message. Try sending a trigger like "launch a token" to test it!
