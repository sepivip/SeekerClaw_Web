How to Install Your Skill

Option 1: Send to Your Agent Easiest

Send the skill to your SeekerClaw agent in Telegram — either way works:

  • Paste the text: Copy the SKILL.md content and send it as a message:
"Save this as a skill called {name}:

[paste the SKILL.md content here]"
  • Send as a file: Download the .md file and send it directly to your agent in Telegram. It will read and install it automatically.

Option 2: Use Claude Code

If you used the "Claude CC Prompt" mode, paste the generated prompt into Claude Code. It will create the skill file — then send the resulting .md file to your agent in Telegram to install it.

After installation, your agent will automatically detect new skills on the next message. Try sending one of the trigger messages to test it!
